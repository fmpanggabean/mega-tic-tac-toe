Rules

  • Hover over a cell and type a number (1-9).
  • Press Space to clear a number from an active cell.
  • Place a number to claim a cell (+10 pts).
  • Override an opponent's number before the grid is won!
  • Get 3-in-a-row in a small grid to win it (+20 bonus pts).
  • When a grid is won, opponents' points in that grid are nulled!
